# Page « Méthodes » Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une page `/methodes` qui liste les 883 méthodes de fabrication du jeu, où le joueur coche celles qu'il connaît et voit, pour les autres, où les obtenir.

**Architecture:** Un script d'import (Serebii `crafting.shtml` + noms Pokékalos) produit `src/data/methodes.json` et les vignettes manquantes ; la normalisation des sources vit dans un module pur testé. Les coches vivent dans un store localStorage partagé (même schéma que `villesStorage.js`). La page et la fiche objet lisent les deux.

**Tech Stack:** React 18, antd 5, react-router 6, Vite 5 ; scripts Node ESM ; tests `node --test` (aucun lanceur n'existe encore) ; conversion webp via Python + Pillow (présent sur la machine).

**Spec:** `docs/superpowers/specs/2026-10-24-methodes-design.md`

## Global Constraints

- Tout texte visible est en français ; le nom anglais reste cherchable (`correspond` de `src/utils/recherche.js`).
- Clé de stockage `pokopia:methodes` ; export `{ format: 'pokopia:methodes', version: 1, connues: [...] }` ; l'import **ajoute**, n'efface jamais.
- Une coche dont le nom n'est plus dans `methodes.json` est **conservée** mais **non comptée**.
- Le compteur se calcule sur `methodes.json`, jamais 883 en dur.
- Zones → clés de `src/data/villes.js` : Withered Wasteland(s) → `terrassec`, Bleak Beach → `grisemer`, Rocky Ridges → `collinangle`, Sparkling/Sparkly Skylands → `flotiles`, Palette Town → `ville-nouvelle`, Bubbly Basin → `fonds-bulleux`.
- Vignettes : objet du catalogue → son sprite actuel ; sinon `src/data/sprites/methodes/<slug>.webp`, 72 px.
- Scripts : télécharge et compare sans rien écrire ; `--ecrire` applique ; `--local <dossier>` part de pages déjà téléchargées. En-tête de commentaire en français comme les autres scripts.
- Commits en français, au style du dépôt (« Page Méthodes : … »), terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- Texte de source Serebii jamais vu (faute de frappe, nouvelle zone) → classé `autre`, texte d'origine affiché, et imprimé par l'import ; jamais de ligne perdue. *(test Task 1)*
- localStorage corrompu ou indisponible → la page s'ouvre avec zéro coche, sans planter. *(test Task 3)*
- Import d'un export d'une autre app (`pokopia:habitats`) ou de JSON invalide → message d'erreur, aucune coche touchée. *(test Task 3)*
- Recherche « coffre » ou « chest » → trouve la même méthode ; accents ignorés. *(vérifié Task 5)*
- Objet du catalogue au nom de casse différente chez Serebii (« Adventure Kit » / « Adventure kit ») → relié à sa fiche, une seule ligne. *(test Task 1)*

### Task 1: Normalisation des sources et des noms (module pur)

**Files:**
- Create: `scripts/lib/methodes.mjs`
- Test: `scripts/lib/methodes.test.mjs`
- Modify: `package.json` (script `"test": "node --test scripts/"`)

**Interfaces:**
- Produces:
  - `cleNom(s: string): string` — entités HTML décodées (`&eacute;`, `&amp;`, `&#39;`…), apostrophes ’ → ', minuscules, sans diacritiques, sans non-alphanumériques. Sert à tout appariement (catalogue, Pokékalos).
  - `decoderEntites(s: string): string`
  - `sources(texte: string): Source[]` où `Source = { type: 'boutique'|'offre-du-jour'|'remous'|'expansion'|'histoire'|'autre', zone?: string, niveau?: number, lot?: string|true, texte: string }` — `texte` est la portion d'origine, nettoyée des espaces doubles.
  - `CLES_ZONE: Record<string,string>` (nom Serebii normalisé → clé de ville).

- [ ] **Step 1: Write the failing tests** (`node:test` + `node:assert/strict`)

```js
test('boutique de zone avec niveau', () =>
  assert.deepEqual(sources('Shop - Bleak Beach Lv. 2'),
    [{ type: 'boutique', zone: 'grisemer', niveau: 2, texte: 'Shop - Bleak Beach Lv. 2' }]))
test('variantes d’orthographe de zone', () => {
  assert.equal(sources('Shop  - Sparkly Skylands Lv. 3')[0].zone, 'flotiles')
  assert.equal(sources('Shop - Withered Wasteland Lv. 1')[0].zone, 'terrassec')
})
test('lot', () => {
  assert.equal(sources('Shop (as bundle) - Palette Town Lv. 2')[0].lot, true)
  assert.equal(sources('Shop (as bundle) - Mountain House Recipe Set')[0].lot, 'Mountain House Recipe Set')
})
test('offre du jour, casse libre et condition', () => {
  assert.equal(sources('Daily shop special')[0].type, 'offre-du-jour')
  assert.equal(sources('Daily shop special after Treasure Map found')[0].type, 'offre-du-jour')
})
test('remous', () => {
  for (const t of ['Sparkling Water', 'Sparkling ripples in water', 'Random chance in whirlpools'])
    assert.equal(sources(t)[0].type, 'remous')
})
test('deux sources dans un texte', () =>
  assert.deepEqual(sources('Bubbly Basin whirlpools or daily shop special').map((s) => s.type),
    ['remous', 'offre-du-jour']))
test('expansion, histoire', () => {
  assert.equal(sources('Expansion Pass only')[0].type, 'expansion')
  assert.equal(sources('From Chef Dente during the story')[0].type, 'histoire')
  assert.equal(sources('Beginning')[0].type, 'histoire')
})
test('inconnu → autre, texte gardé', () =>
  assert.deepEqual(sources('Obtain a Vine rope'), [{ type: 'autre', texte: 'Obtain a Vine rope' }]))
test('cleNom', () => {
  assert.equal(cleNom('Pok&eacute; Ball Chest'), cleNom('Poké Ball chest'))
  assert.equal(cleNom('Adventure Kit'), cleNom('Adventure kit'))
})
```
